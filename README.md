# swamp-todoist-watcher

[swamp](https://swamp.club) extension `@mgreten/todoist-watcher` — a
multi-machine Todoist task watcher and dispatcher that scans trigger-labelled
tasks, respects schedule windows, deduplicates with TTL claims, and emits a
structured dispatch list for a host executor.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/todoist-watcher`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
